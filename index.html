Coding Companion for RevolutionEHR

By Dr. Earls Optometry Tools

A browser extension for eye-care practices that use RevolutionEHR: build the codes for an exam type once, then add them to an encounter in one step.

It is in a private beta. It keeps everything in your browser and sends nothing anywhere. Privacy statement.
