Coding Companion for RevolutionEHR: privacy

Published by Dr. Earls Optometry Tools · Last updated September 26, 2026

Coding Companion does not collect, send or sell any information. Everything it keeps stays in your browser on your computer, and it makes no network requests of its own.

What it keeps on your computer

In the browser's own storage for this extension:

  • Your Packages: the diagnosis codes, plan text and service codes you build or import. They contain no patient information.
  • A copy of your practice's service list (service codes, descriptions and RevolutionEHR's ids for them), taken only when you click Refresh service list, so the Package Builder can search it.
  • Code check results: which of your Packages' codes RevolutionEHR accepted, and when.
  • Small display preferences, such as how the Package Library is sorted.

Removing the extension deletes all of this.

What it reads in RevolutionEHR

Coding Companion only runs on revolutionehr.com. When you apply a Package, it reads the diagnoses and services already on the open encounter, so that it doesn't add a code twice and can attach diagnoses to the right service lines. It then enters the codes and plan text you confirmed, through RevolutionEHR's own screens. What it reads from the encounter is used for that one action and is not stored or sent anywhere.

Network use

The extension sends nothing over the internet. It has no analytics, no tracking, no advertising and no remote code. The only network traffic while it works is RevolutionEHR's own, the same as when you enter codes by hand.

Files you create

Export saves your Packages to a file only when you click it, in a place you choose. The Diagnostics self-check shows a report on screen and copies it only when you click; it contains counts and technical details, not patient information.

Sharing

No information is shared with anyone, including the publisher.

Independence

Coding Companion for RevolutionEHR is an independent tool. It is not made by, endorsed by or affiliated with RevolutionEHR.
